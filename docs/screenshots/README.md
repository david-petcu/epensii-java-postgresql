# Capturi de ecran

Înainte de publicare, adaugă în acest director următoarele imagini PNG:

- `dashboard.png` — fereastra principală și indicatorii dashboardului;
- `registru.png` — registrul cererilor cu filtrele vizibile;
- `validare.png` — un dosar aflat în etapa de verificare;
- `salarii.png` — editorul salariilor cu anii calendaristici.

Folosește date complet fictive și evită includerea altor aplicații, notificări sau informații personale în capturi. Recomandare: format PNG și o lățime de aproximativ 1200–1600 px.
